# Данные проекта

## Источник

**UCI Online Retail II** — обезличенные транзакции британского онлайн-ритейлера
(подарки/товары для дома), декабрь 2009 → декабрь 2011.

- 🔗 https://archive.ics.uci.edu/dataset/502/online+retail+ii
- Объём исходника: **1 067 371 строка** (строка = позиция в чеке)
- 43 страны · ~5 900 клиентов · ~5 300 товаров

## Что лежит в этой папке

| Файл | Что это | Строк |
|---|---|---|
| `Dim_Customer.csv` | Справочник клиентов (CustomerID, Country) | 5 943 |
| `Dim_Product.csv` | Справочник товаров (StockCode, Description, IsProduct) | 5 131 |
| `Dim_Date.csv` | Календарь (день, месяц, год, квартал, день недели) | 739 |
| `Fact_Sales_sample.csv` | **Сэмпл** таблицы продаж (первые 5 000 строк) | 5 000 |

> Полная таблица `Fact_Sales` (~89 МБ, 1.03 млн строк) в репозиторий **не коммитится** —
> её легко воспроизвести из исходника по шагам ETL (см. кейс проекта).
> В репозитории — представительный сэмпл + справочники целиком.

## Схема `Fact_Sales_sample.csv`

| Колонка | Тип | Описание |
|---|---|---|
| `Invoice` | text | Номер чека (для DISTINCTCOUNT заказов) |
| `StockCode` | text | Код товара → связь с `Dim_Product` |
| `Quantity` | int | Количество (в продажах всегда > 0) |
| `Price` | decimal | Цена за единицу (> 0) |
| `Revenue` | decimal | `Quantity × Price` |
| `InvoiceDate` | datetime | Дата и время чека |
| `DateKey` | int | Ключ даты → связь с `Dim_Date` |
| `CustomerID` | text | Клиент → связь с `Dim_Customer` |
| `Country` | text | Страна |
| `IsCancelled` | bool | Признак отмены/возврата |

## Как воспроизвести полную модель

1. Скачать `online_retail_II.csv` по ссылке выше.
2. Загрузить в Power BI через **Get Data → Text/CSV**.
3. Повторить шаги очистки из кейса проекта (см. `../README.md`, раздел «ETL»).
4. Меры и вычисляемые столбцы — в `../dax/`.
