# Файл отчёта

Сюда положи готовый Power BI файл под именем **`ecommerce-customer-analytics.pbix`**.

Он подключается к репозиторию через **Git LFS** (см. `.gitattributes` в корне) —
это правильный способ хранить крупные бинарники в git.

Сюда же — `report.pdf` (экспорт всего отчёта), чтобы отчёт можно было посмотреть
без Power BI Desktop.

## Перед коммитом — обязательный чек-лист по модели

- [ ] Удалить из модели сырую таблицу `online_retail_II (1)` (снять «Enable load»
      или удалить запрос) — иначе датасет дублируется, файл раздут вдвое.
- [ ] Выключить **Auto date/time** (Options → Data Load) — убирает ~10 скрытых
      таблиц дат и лишний вес.
- [ ] Сверить цифры в README с фактическими (см. кейс: £20.12M / 1.03M строк).
- [ ] Убрать слайсер `Year` со страницы Cohort Retention (искажает Retention %).
- [ ] Экспортировать `report.pdf` и снять 5 скриншотов в `../images/`.
