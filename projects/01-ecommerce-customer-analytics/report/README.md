## Рекомендации по доработке модели (по желанию)

- [ ] Удалить из модели сырую таблицу `online_retail_II (1)` — дубликат на 1 млн строк,
      раздувает файл (снять «Enable load» или удалить запрос).
- [ ] Выключить **Auto date/time** (Options → Data Load).
- [ ] На странице *Executive Overview* блок **Data Quality** ещё показывает старые
      цифры (£17.74 млн / 805 549) — привести к фактическим (£20.12 млн / 1.03 млн),
      как в KPI сверху. После правки — пере-экспортировать `report.pdf`.
